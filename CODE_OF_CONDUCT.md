# Code of Conduct

## Our Commitment

We follow the **Contributor Covenant v2.1**.
Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Short version: be respectful, be collaborative, be patient.

## Scope

This code of conduct applies to all activity in this repository:
- GitHub Issues
- Pull Requests
- Discussions
- Code review comments
- Any other project spaces

## Reporting

For **non-sensitive concerns** (tone, minor friction), open a GitHub Issue tagged
`code-of-conduct` and describe what happened.

For **sensitive matters** (harassment, private information, serious violations),
use GitHub's built-in [report-content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature, which keeps your report private.

Please do not post sensitive reports in public issues.

## Enforcement

Maintainers will:
1. Acknowledge receipt within 7 days.
2. Review the report and gather context.
3. Determine the appropriate response.

Possible outcomes range from a private warning to a temporary ban to a
permanent ban, depending on the nature and severity of the violation.

Maintainers who do not follow or enforce this code of conduct in good faith
may face consequences as determined by the project leadership.
